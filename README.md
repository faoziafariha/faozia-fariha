# Faozia Fariha — Portfolio

Responsive single-page portfolio built from scratch with vanilla **HTML, CSS, and JavaScript** — no frameworks, no build step.



##  Project structure

```
portfolio/
├── index.html      # Page markup + content
├── styles.css      # Theme, layout, animations
├── script.js       # Typewriter, reveal, nav, parallax
└── README.md       # You are here
```

##  Run locally

Just open `index.html` in a browser, or:

```bash
# from this folder
python -m http.server 5173
# then visit http://localhost:5173
```

Live Demo - https://faozia-fariha-faozia-farihas-projects.vercel.app/
```
